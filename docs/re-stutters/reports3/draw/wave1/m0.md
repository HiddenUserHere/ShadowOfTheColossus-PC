# m0: draw-work metric, op counts, matrix column, profile archive

Written by the coordinator from the agent's hand-back (the agent did not write the file). Nothing was run in game.

## What changed
- `gpu/shadps4/video_core/sotc_stats.h`: `kDrawWork` (`SOTC_DRAW_WORK`, off by default, counting only);
  `NoteDrawOp(SplitPart)`; `FrameDrawOps` + `TakeFrameDrawOps()`; `DrawWorkReport(flips, idle_ms)`.
- Line: `SOTC DRAW WORK: X ms/frame (ops Y ms, commands Z ms, readbacks R ms, flip wait F ms; ops N/frame)`.
  - X = (window - idle - F) / flips: the draw thread's work. X > Y + Z (BackLoop overhead, express replays).
  - Y = ExecuteBackOp time by kind (draw, indirect, dispatch, func). Z = ProcessCommands callbacks.
  - R = guest readback waits (not draw-thread time, not in X). F = SplitWaitFrame (draw thread only).
  - Needs `SOTC_FPS=1` and `SOTC_DRAW_SPLIT=1`; otherwise the line says "unavailable".
- SOTCSTALL gets `ops N (draws D, dispatches P)` per frame (vk_presenter.cpp, needs SOTC_DRAW_WORK=1).
- `tools/pcmem_matrix.py`: column "draw work ms/frame"; COMMON_ENV sets `SOTC_DRAW_SPLIT=1 SOTC_DRAW_WORK=1`
  (a clock read per op and per bind: "draw busy" from these runs is not comparable with older lots).
- `tools/sotc_run.sh`: copies the exe to `${SOTC_PROFILE_OUT}.exe`; `tools/profile_functions.py` takes the exe
  argument optionally (default `<dump>.exe`, else out/gpu/bb-probe.exe).
