  - Symptoms: horse copies and grass without alpha. The root cause was not found; the suspicion is wrong bytes

  - A host-side `is_texel` plumbing change makes formatted reads go through `ObtainBuffer`'s image sync

    `OnPageMiss` still passes `is_texel=false`.

  - The globals address is valid (`0x1fa00000`).
  - Diagnostics print `SOTC GCN GLOBALS: created...` and `SOTC GCN PACKET: word 88...`.
- **Table mode is much worse on a cold cache.**
  - Its compute pipelines are expensive to compile.
  - Table-mode pretranslate was tried and reverted: it built about 16k unused programs, the loading screen took

- **`SOTC_ADDR_FALLBACK`** (a descriptor-mode pipeline is used while the table variant compiles) is
  implemented. It broke the image (dark terrain, ghosting) and the table pipelines never became ready, so it is
  default off (`vk_pipeline_cache.cpp` ~636).

### C. First-launch correctness and stutter: the current work

- **Root cause (confirmed by the user visually):**
  - On a cold cache, draws whose graphics pipeline is still queued are dropped
    (`vk_pipeline_cache.cpp` nullptr returns; `vk_rasterizer.cpp` ~3130 returns before recording).
  - Whole passes vanish for seconds. The result is fog at full strength, ghosting and dark terrain.
  - Depth-only draws were dropped too, although a comment said they never were.
  - Compute pipelines are not dropped, but the recorder waits for them: about 10 s per cold route, freezes up to
    7 s.
  - A cold run with `SOTC_NB_WORKER_CAP=0 SOTC_DEPTH_SYNC_PIPE=1` rendered correctly, but stalled 4–7 s.
- **Fix in progress: `SOTC_PIPE_MANIFEST`** (default on, uncommitted).
  - New files: `gpu/sotc/pipe_manifest.{h,cpp}`, `tools/gen_pipeline_manifest.py`,
    `data/pipeline_manifest/sotc-pipelines.tsv`.
  - The manifest is a TSV holding only hashes and numeric state: header `H`, stages `S`, graphics `G`,
    compute `C`.
  - Every session appends missing keys to `user/shader_predict/sotc-pipelines.user.tsv`. Stages that cannot be
    rebuilt go to `sotc-pipelines.skip.tsv`.
  - **Boot build:** at the game-start loading screen, the shipped and user manifests are translated from the
    game's own loaded shaders on all workers, and the loading screen is held until they are built.
    - A translation is installed only if its specialization equals the recorded one.
    - Log lines start with `SOTC PIPE MANIFEST:`. The `ASYNC TRANSLATE` line now ends with
      `pipeline-pending draws dropped N`.
  - **Also in this change:**
    - Depth-only draws now build synchronously by default; `SOTC_DEPTH_SYNC_PIPE=0` opts out.
    - A missing graphics pipeline is pushed to the front of its queue.
    - The compute-hints bug is fixed: hints were keyed by the variant-mixed hash and never applied.
    - `sotc.py` sets `SOTC_RES_LOADED` and `SOTC_PIPE_MANIFEST_DIR`.
    - `package_sotc.sh` copies `data/pipeline_manifest/`.
